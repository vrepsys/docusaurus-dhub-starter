# Welcome

This site is built with [Docusaurus](https://docusaurus.io) and set up for [Dhub](https://dhub.dev) — a Notion-like editor for documentation that keeps everything in sync with your GitHub repo.

If you're reading this in Dhub, this page is editable. Click anywhere and start typing — nothing is published until you push.

## A quick tour

The pages in the sidebar double as a tour of what you can do:

- **Editing** — start with [Edit a page](./editing/edit-a-page.md), then try the block types: [callouts](./editing/callouts.md), [tabs & toggles](./editing/tabs-and-toggles.mdx), [code blocks & tables](./editing/code-blocks-and-tables.md), [images](./editing/images.md), and [custom components](./editing/custom-components.mdx).
- **Publishing** — how the [sidebar navigation](./publishing/navigation.md) works, how to [push changes or open a pull request](./publishing/push-and-pull-requests.md), and how to [deploy your site](./publishing/deploy.md).
- **[Make it yours](./make-it-yours.md)** — a short checklist for turning this template into your own site.

Every example on these pages is live. Edit them, break them, undo — it's all just your draft until you push.

:::tip[Try it]
Place your cursor on an empty line and type `/` to see everything you can insert.
:::

## Not in Dhub yet?

If you're reading this on the web and haven't imported the project:

1. Fork the [template repository](https://github.com/vrepsys/docusaurus-dhub-starter)
2. [Sign up for Dhub](https://dhub.dev) and import your fork
3. Start editing

No local setup is needed to edit and publish content.
